# Salesforce Admin Practice

Hands-on Salesforce Admin configuration practice completed in a Developer Org.

## What I built

- **Permission Set**: Created a custom permission set ("Practice Support Access") to manage user-level access.
- **Object Permissions**: Configured Read, Create, and Edit permissions on the Account object.
- **Validation Rule**: Built a validation rule using formula logic (`ISPICKVAL`) to require a phone number for accounts marked as "Customer" type.
